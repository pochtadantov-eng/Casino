# Картинки для плашек лобби

Положите файл сюда с именем `<ключ>.<формат>` — плашка подхватит его сама, код менять не нужно.
Удалите файл — вернётся встроенная картинка.

| Ключ      | Плашка            |
|-----------|-------------------|
| `bonus`   | Ежедневный сундук |
| `mines`   | Мины              |
| `rocket`  | Ракета            |
| `tower`   | Башня             |
| `dig`     | Шахта             |
| `plinko`  | Плинко            |
| `slot`    | Слот 777          |
| `luck`    | Кейсы · Удача     |
| `seagull` | Чайка             |

Форматы (проверяются по порядку): `webm` (видео с прозрачностью, зациклено), `webp` (анимированный), `gif`, `png`.
Рекомендуется: квадрат 512×512, прозрачный фон, зацикленная анимация, до 300 КБ.
