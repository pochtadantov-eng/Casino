# Stars Casino — Telegram Mini App

NestJS + grammY + PostgreSQL. Баланс пополняется Telegram Stars (XTR). Подарки — этап 2.

## Игры
| Игра | Механика |
|---|---|
| 🚀 Ракета | Множитель растёт по времени, нужно успеть «Забрать» до краша. Есть авто-вывод (работает и если игрок закрыл приложение). |
| 💣 Мины | Поле 5×5, 1–24 мин, каждая открытая клетка повышает икс. |
| 🏗 Башня | 10 этажей, на каждом выбираешь блок; 4 уровня сложности. Чем выше — тем больше икс. |
| 🕊 Чайка | Чайка летит над 3 детьми и хватает одного; угадай, кого она **не** заберёт. 12 шагов, икс растёт с каждым. |

RTP всех игр 97% (`HOUSE_EDGE` в `src/games/engines/types.ts`); проверяется симуляцией в `test/engines.spec.ts`.
Исход каждого раунда определяется сидом до первого хода, а лимит выплаты (`MAX_PAYOUT`) ограничивает риск.

## Честность (provably fair)
Перед раундом игрок видит `sha256(serverSeed)`, после — сам `serverSeed`. Все случайные числа:
`HMAC_SHA256(serverSeed, clientSeed:nonce:i)` (`src/fair/fair.ts`) — любой раунд можно переиграть.

## Запуск
```bash
cp .env.example .env        # BOT_TOKEN, WEBAPP_URL, DATABASE_URL ...
docker compose up -d db
npm install && npm run build && npm start   # API + бот + Mini App на :3000
npm test
```
Mini App нужен публичный HTTPS (ngrok / cloudflared / домен): укажите его в `WEBAPP_URL` и в @BotFather → Mini App.
Локально без Telegram: `DEV_AUTH=1` и открыть `http://localhost:3000/?dev=123` (**только для разработки**).

## Деньги
- Депозит: `/deposit` или кнопка «Пополнить» → инвойс в XTR → `successful_payment` → зачисление (идемпотентно по `telegram_payment_charge_id`).
- Все изменения баланса идут через `WalletService.apply` в транзакции, с записью в `transactions`; баланс не может уйти в минус.
- Вывод: заявка (`/withdraw`, кнопка «Вывод») → админ из `ADMIN_IDS` делает `/pending`, `/approve <id>` или `/reject <id>` (отказ возвращает деньги).
  **Выплата Stars игроку Bot API напрямую не поддерживает** — сейчас одобрение только фиксирует заявку, а перевод делается вручную.
  Автоматическая выплата возможна через подарки (`sendGift`) — это этап 2.

## Структура
`src/games/engines/*` — чистые движки игр · `src/games/games.service.ts` — раунды/ставки/выплаты · `src/wallet` — баланс и леджер ·
`src/bot` — grammY (оплата Stars, админ-команды) · `src/auth` — проверка `initData` · `webapp/` — клиент.

## Перед запуском в проде
- Правила Telegram: проверьте допустимость использования Stars в азартных играх — иначе бот и возможность принимать Stars могут быть заблокированы.
- Лицензия/юрисдикция на азартные игры, 18+, KYC/AML, ответственная игра — на стороне владельца.
- Rate limiting, webhook вместо long polling, бэкапы БД, мониторинг, лимиты на игрока.
